FOLDER GAMBAR PRESTASI

Taruh gambar asli Anda di folder ini, misalnya:
prestasi1.png
prestasi2.jpg
prestasi3.jpeg
prestasi4.png

Nama file harus huruf kecil, tanpa spasi, tanpa nol di depan nomor.
Anda boleh mencampur PNG, JPG, dan JPEG. Satu nomor untuk satu prestasi.
Jika nomor sama memiliki lebih dari satu format, prioritas: PNG, JPG, JPEG.
Nomor yang kosong dilewati. Default memeriksa nomor 1 sampai 100.
Untuk lebih banyak gambar, ubah prestasiMax di config.js.

Upload folder asset beserta gambar ke repository dan tunggu deploy selesai.
Halaman prestasi.html mendeteksi gambar tanpa perlu mengedit HTML.
Folder assets (dengan s) tetap dipakai untuk CV dan favicon; jangan dihapus.
Tidak ada gambar prestasi palsu yang disertakan.
